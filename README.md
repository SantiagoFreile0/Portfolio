# Santiago Freile | Data Science & Machine Learning Portfolio

Welcome to my portfolio. I apply machine learning across different domains, lately focused on NLP applied to finance. I am also drawn to computational neuroscience, particularly using CNNs to understand how artificial neural networks relate to the biological systems that inspired them. Still exploring, but that intersection is where my curiosity lives right now.

## Projects

1. [Stock Price Movement Prediction (NLP, PyTorch, ALBERT)](./stock-movement-albert)

A fine-tuned ALBERT model that classifies financial news headlines as bullish or bearish. The project includes full exploratory analysis, stratified data splitting, model training, and behavioral probing experiments that reveal where the model fails and why. Built independently using PyTorch and HuggingFace Transformers.

2. [Bank System Database (SQL, Python, BI Tools)](./bank-system-database)

A relational database system simulating real banking operations across 17 structured tables, with views, triggers, and stored procedures. Connected to Python and BI tools for portfolio analysis and dashboards.

3. [Real Estate Price Estimator (R & Shiny)](./real-estate-price-estimator)  

An interactive web application that estimates housing prices based on property characteristics, built with R and Shiny.

4. [UFC Stance Analysis (Statistics, Visualization)](./ufc-stance-analysis)  

A statistical analysis of UFC fighters exploring whether fighting stance correlates with performance outcomes.
