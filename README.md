# Santiago Freile | Data Science & Machine Learning

Welcome to my portfolio. I apply machine learning across different domains, lately focused on NLP applied to finance. I am also drawn to computational neuroscience, particularly using CNNs to understand how artificial neural networks relate to the biological systems that inspired them. Still exploring, but that intersection is where my curiosity lives right now.

---

### [Stock Price Movement Prediction (NLP, PyTorch, ALBERT)](./stock-movement-albert)
A fine-tuned ALBERT model that classifies financial news headlines as bullish or bearish. Full exploratory analysis, stratified data splitting, model training, and behavioral probing experiments that reveal where the model fails and why.

### [Image Classification with ResNet-18 (PyTorch, Transfer Learning)](./resnet18-imagenette)
A 10-class image classifier built with transfer learning on an intentionally imbalanced dataset. Achieves 97.35% overall accuracy. The per-class analysis reveals how class imbalance interacts with visual distinctiveness in ways that overall accuracy alone cannot capture.

### [Bank System Database (SQL)](./bank-system-database)
A relational database system simulating real banking operations across 17 structured tables, with views, triggers, and stored procedures.

### [Real Estate Price Estimator (R, Shiny)](./real-estate-price-estimator)
An interactive web application that estimates housing prices based on property characteristics.

### [UFC Stance Analysis (R, Statistics)](./ufc-stance-analysis)
A statistical analysis of UFC fighters exploring whether fighting stance correlates with performance outcomes.
