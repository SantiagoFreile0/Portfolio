# Santiago Freile | Data Science & Machine Learning Portfolio

Welcome to my Data Science portfolio. Here you will find projects focused on finance, neuroscience, cybersecurity, and sports analytics.

Across these projects, I work with machine learning, statistical modeling, data analysis, visualization, and database systems to understand patterns and turn raw data into useful information. My focus is on building systems and models that support real decisions, especially in financial and analytical environments.

## Projects

1. [Bank System Database (SQL, Python, BI Tools)]

Designed and built a relational database system that simulates real banking operations, including accounts, transactions, loans, and customer portfolios.

The system includes 17 structured tables, along with views, triggers, and stored procedures to automate workflows and maintain data integrity. I also connected the database to Python and business intelligence tools to analyze customer activity, evaluate portfolios, and generate dashboards.

This project demonstrates how database design and analytics can support financial decision-making and operational efficiency.

2. [Real Estate Price Estimator (R & Shiny)](./real-estate-price-estimator)  

An interactive web application built with R and Shiny that estimates housing prices based on property characteristics such as size, location, and features.

The project uses statistical modeling, data visualization, and geographic mapping to help users understand what drives property values. Future plans include integrating machine learning models to improve prediction accuracy.

3. [OSINT Tool (Python)](./osint-tool)  

A Python application that gathers publicly available information by searching names and usernames across multiple online platforms.

Built to support open-source intelligence workflows, this tool automates the process of collecting and organizing publicly available digital footprints.


4. [UFC Stance Analysis (Statistics & Visualization)](./ufc-stance-analysis)  

A statistical analysis of UFC fighters to identify patterns between fighting stance and performance outcomes.

This project uses data analysis and visualization to explore whether certain stances are associated with higher win rates or competitive advantages.
